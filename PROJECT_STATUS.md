## 🚀 **HOW TO RUN**

### **Prerequisites:**
```bash
Python 3.10+ (recommended) or 3.13.3 (current environment)
```

### **Installation:**
```bash
# Install dependencies
pip install -r requirements.txt

# For Python 3.13.3 environment (current):
pip install streamlit pandas numpy plotly yfinance scipy cvxpy xgboost scikit-learn gymnasium ta fpdf2 seaborn matplotlib --break-system-packages
```

### **Launch:**
```bash
streamlit run app.py
```

### **Testing:**
```bash
# Quick functionality test
python3 quick_test.py

# Comprehensive validation (with limitations)
python3 validate_finoptima.py
```
